## 🌟 Features

### 📊 Data Layers
- **Conflicts** - Real-time conflict zone monitoring
- **Military Bases** - Global military installation tracking
- **Hotspots** - Global tension hotspots
- **Nuclear** - Nuclear facilities and activity
- **Sanctions** - International sanctions tracker
- **Weather** - Extreme weather events worldwide
- **Economic** - Economic indicators and trends
- **Waterways** - Critical waterway monitoring
- **Outages** - Infrastructure and power outages
- **Military Movements** - Troop and equipment movements
- **Natural Disasters** - Natural disaster tracking
- **Iran Attacks** - Regional conflict monitoring

### 🎨 Interface Features
- Interactive global map with zoom controls
- Layer toggle system
- Time range selector (24h, 7d, 30d, 90d, 1y)
- Real-time data updates
- Dark/Light mode
- Mobile responsive design
- AI-powered insights and predictions
- Data visualization charts
- News aggregation
- Export capabilities

## 🚀 Quick Start

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
